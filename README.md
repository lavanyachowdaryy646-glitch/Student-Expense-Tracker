# Student Expense Tracker

A simple and user-friendly web application to track daily student expenses.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Filter expenses by category
- Calculate total expenses
- Show number of expenses
- Show highest expense
- Set monthly budget
- Calculate remaining budget
- Save expenses using Local Storage
- Mobile-friendly design

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Categories

- Food
- Travel
- Education
- Shopping
- Other

## How to Use

1. Enter your monthly budget.
2. Enter the expense amount.
3. Select a category.
4. Select the date.
5. Enter a description.
6. Click "Add Expense".
7. Use Edit or Delete when needed.
8. Use the category filter to view specific expenses.
